How installation works

About a minute per tool. Nothing is written outside your own Windows user folder.

  1. Download the setup file

    Choose a tool above and save its setup file. Windows 10 or 11, 64-bit.

  2. Run it

    If Windows SmartScreen shows a warning, choose More info and then Run anyway.

  3. Choose your Revit versions

    The versions installed on your PC are already ticked. Close those Revit sessions before you continue.

  4. Activate

    Start Revit, choose Always Load, and enter your SADA activation key.

Questions

Where are the files installed?

Revit add-ins go to %APPDATA%\Autodesk\Revit\Addins\<year>. The ETABS Toolkit and File Renamer Pro go to %LOCALAPPDATA%\Programs. Struct Helper PC is portable and runs from wherever you unzip it.

How do I update a tool?

Download the newer setup file and run it over the old version. Your activation key and settings are kept.

How do I remove a tool?

Open Windows Settings, then Apps, then Installed apps. Find the SADA tool and choose Uninstall. Close Revit first.

Which tools need an activation key?

Struct, Steel and Arch are activated separately. The Parapet Tool uses the Struct key. The ETABS Toolkit, File Renamer Pro and the Struct Helper apps need no key.

Why does Windows SmartScreen warn me?

SmartScreen warns about setup files that are not yet widely downloaded. Choose More info, then Run anyway. You can confirm the file is genuine by checking its SHA-256, shown under Install details on each tool.

How do I check a download?

In PowerShell run Get-FileHash .\SetupFile.exe. The hash it prints must match the SHA-256 listed for that tool.
